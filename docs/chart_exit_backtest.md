# K线持仓与条件式再上车回测

`backtest-chart-exit` 是 report-only 研究命令，不会修改 `recommend`、生产模型指针或生产配置。

它在完全相同的月度建仓路径上，配对比较五种策略：

- `H_hold`：一直持有到 20/40/60 日路径终点。
- `A_pure_2pct`：纯 2% 跟踪止损，用作紧风控参照。
- `B_production`：当前 `make_risk_decision` 的生产 ATR/模型止损镜像。
- `C_chart_exit`：K线/均线退出 + 分段利润底，不再上车。
- `D_chart_reentry`：C + 条件式再上车；实际次数由信号决定。

## C/D 固定结构 v2

盘中只保留成本下方 5% 的灾难止损。初始阶段的结构失效、时间失败、趋势破坏和利润保护全部使用收盘确认并在次日开盘退出，普通下影线不会单独触发卖出。持仓收盘达到 `+1R`、站上 MA20 且 MA20 斜率为正后进入趋势阶段；连续两次收盘跌破 MA20 且跌破已确认 swing low，或一次收盘跌破 MA60，才确认趋势退出。

利润底只使用当时已经看到的最高收盘价，不使用盘中最高价：

- 浮盈不足 8%：不启用利润底；
- 浮盈 8%–15%：利润底为成本上方 0.5%；
- 浮盈 15%–30%：锁住峰值利润的 50%；
- 浮盈达到 30%：锁住峰值利润的 60%。

D 没有“固定重新上车一次”的规则。退出后冷却至少 2 个交易日；收盘重新站上 MA20、MA20 斜率为正、并突破退出 K 线高点和近期平台高点时，才在次日开盘重新上车。硬止损后的重新上车还必须满足 MA20 > MA60。`max_entries_safety=3` 只是防止异常高频的工程保险上限，不是策略目标。

## 成交与评测

所有策略都计入佣金、卖出印花税和滑点。收盘确认信号按次日开盘成交；盘中止损沿用市场/限价成交模拟，保留跳空与限价未成交。评测以扣费后区间收益和趋势保留为主，以 p05、平均最大亏损和最大回撤不比生产 B 明显恶化为硬约束，并输出 walk-forward 与配对 bootstrap。

固定参数用于验证结构，不做网格寻优；D 的再上车规则本轮不调参，只作为增量对照。

```powershell
.\.venv\Scripts\tpsl.exe --config config.toml backtest-chart-exit `
  --start-date 2024-01-01 `
  --end-date 2026-03-31 `
  --max-symbols 300
```

输出位于 `output/chart-exit/<run_id>/`：

- `summary.json`：总汇总、C/D 相对生产 B 的判据；
- `chart_paths.csv`：每条路径、每个策略的结果；
- `trade_ledger.csv`：每次入场、退出、退出原因和单笔收益；
- `walk_forward_summary.json`：逐窗口和 bootstrap 结果；
- `walk_forward_paths.csv`：进入验证窗口的配对路径。
